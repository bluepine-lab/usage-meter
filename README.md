# 使用量メーター

> 個人の試作・初版です。動作は参考情報で、保証はしません。

Claude Code の画面の下に、使用量(5時間枠・7日枠・会話の長さ)を棒グラフで出します。使用量を自動で記録し、使いすぎそうな時に知らせます。

## 先に知っておいてほしいこと

**Python 3 が必要です。** 入っていない場合、導入は「Pythonが必要です」と伝えて止まります。Pythonなしで使う簡易版はありません。

- Pythonの確認: ターミナルで `python --version`(無ければ `python3 --version`)
- 入れたくない人は、無理に使わなくて大丈夫です。Claude Code 標準の `/usage` でも数字は見られます
- 追加のライブラリは要りません(Pythonに最初から付いているものだけで動きます)
- Claude Code 専用です。他のAIツールでは動きません。表示も Claude Code の画面下だけです
- 動作確認は Windows のみです。Mac・Linux は動く想定で、確認していません

## 安全性について(何をするか、全部書きます)

「安全です」と言い切るより、何をするかを並べます。気になる人はコードを読んでください(スクリプトは `scripts/` の5本だけ、どれも短いです)。

**やること**
- Claude Code が渡してくる使用量のデータを読んで、棒グラフにして表示する
- 使用量が変わるたびに、`~/.claude/usage-meter/usage-log.jsonl` に1行足す(使用量・時刻・セッションID・コスト・行数だけ。**会話の中身は入りません**)
- メッセージを送る時に、使い切りそうなら警告を1回出す
- 「グラフを見せて」と言った時だけ、自分のPCの中で作ったHTMLをブラウザで開く

**やらないこと**
- **インターネットへの通信は一切しません。** 外へ送るための仕組み(urllib・requests・socket など)は、どのスクリプトにも使っていません
- 会話の内容・ファイル・パスワードは読みません
- 設定ファイルを上書きしません(バックアップを取ってから、必要な2か所を足すだけ)
- すでに別のステータスラインを使っている人の設定は、確認なしに置き換えません

**書き換えるもの**
- `~/.claude/settings.json` の `statusLine` 欄と、メッセージ送信時の警告の欄
- `~/.claude/usage-meter/` フォルダ(スクリプト・ログ・設定)
- 書き換える前のバックアップは `settings.json.bak-日時` として残ります

**元に戻す** → `python scripts/install.py --uninstall`(設定は元に戻ります。記録のログだけ残します)

## 入れ方

Claude Code に「使用量メーターを入れて」と頼むのが一番かんたんです。自分で入れる場合:

```
python scripts/install.py
```

入れたあと、Claude Code を再起動すると反映されます。

## 使い方

| やりたいこと | 方法 |
|---|---|
| 推移のグラフを見る | 「使用量のグラフを見せて」(数日たまると推移が見える) |
| 分析する | 「使用量を分析して」(いつ一番使っているか等) |
| グラフの種類を変える | `python scripts/install.py --style line`(line / block / square / dot / none) |
| 外す | `python scripts/install.py --uninstall` |

色は、ふだん灰色・80%以上でオレンジ・90%以上で赤です。表示の数値は参考で、トークン数そのものは出ません。
